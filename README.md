# 決算書図解ツール

貸借対照表（BS）と損益計算書（PL）を入力するだけで、経営状況を1枚の図に自動生成するWebアプリです。

## サービスURL

https://kessansho-diagram-tool-6equtjydtkzbaqbrfggxcd.streamlit.app/

## 機能

- BS・PLのブロック図を自動生成
- 粗利益率・労働分配率・損益分岐点売上高・総資産回転率を自動計算
- 無料プラン：1期表示
- 有料プラン（月額500円）：3期比較・PNG/PDFエクスポート
